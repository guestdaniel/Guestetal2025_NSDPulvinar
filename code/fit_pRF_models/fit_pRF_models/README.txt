This folder contains code used to fit the pRF models.

Execution of the code requires access to the NSD dataset (http://naturalscenesdataset.org), as well as the following code repositories:

- https://github.com/cvnlab/knkutils/
- https://github.com/cvnlab/nsdcode/
- https://github.com/cvnlab/analyzePRF/
- https://www.mathworks.com/matlabcentral/fileexchange/8797-tools-for-nifti-and-analyze-image
